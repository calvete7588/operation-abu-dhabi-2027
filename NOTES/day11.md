**Date:** July 24, 2026

## Objective
Analyze core network devices (Hubs, Switches, Routers, Modems), evaluate Cloud Networking benefits, and master the TCP/IP protocol stack architecture.

## Core Concepts Explained
* **Network Hardware Evolution:**
  * *Hubs:* Legacy layer 1 devices with security vulnerabilities due to uncontrolled traffic broadcasting.
  * *Switches & Routers:* Intelligent hardware directing traffic accurately via MAC and IP addresses.
* **Cloud Networking:** Virtualized network infrastructure offering high availability, rapid scalability, and centralized cloud security management.
* **TCP/IP Model:** 4-layer architectural model (Application, Transport, Internet, Network Access) that governs global data transmission protocols.

## Technical Vocabulary
* **TCP/IP Stack** (/ti-si-pi ai-pi stak/): Conjunto de protocolos de red estructurado en capas.
* **Cloud Infrastructure** (/klaud in-fra-strok-chur/): Infraestructura de red alojada y gestionada en la nube.
* **Broadcast Domain** (/brod-kast do-méin/): Área lógica de red donde los dispositivos reciben paquetes de difusión.
